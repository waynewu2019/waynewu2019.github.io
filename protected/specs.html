Gen1 design targets

These are architecture design targets for the Gen1 validation platform — not silicon-measured values. Targets may change as validation proceeds; measured results are published with their configuration when they exist.

Parameter Gen1 design target
Compute array32,768 compute units per MPU (256 × 128 baseline), FP16 datapath
ProcessTSMC N5P-class
On-chip memory~384 MB SRAM per MPU (baseline)
External memoryCommodity DRAM (GDDR7-class). No HBM
PackagingStandard packaging; no advanced packaging required

Scale64 MPUs per state domain (one rack); the compiler sees one array
SchedulingCompile-time. No runtime routing, no cache coherence, no transaction layer in the fabric

State path

The unit of movement is bounded state, on a compile-time schedule: state leaves a compute node (MPU), crosses the SIF fabric and a fixed-latency optical link, and arrives at the next node — MPU → SIF → fiber → SIF → MPU. The same path, for the same duration, every cycle.

Validation platform configuration

  • Compute nodes: AMD Alveo V80-class FPGA cards (MPU-Lite emulation)
  • Fabric node: AMD Versal VPK120 (SIF-Lite emulation)
  • Inter-node link: single-mode fiber, spool-swap lengths 10 / 50 / 100 / 500 m
  • Proof-of-concept compiler for compile-time state-path scheduling

Full bench configuration for every published measurement accompanies the result.
