Partner Admin

Protected content now ships inside the site itself and unlocks for any signed-in partner account — there are no server functions to manage. Partner accounts are managed directly in the Supabase dashboard.

How access works now

  • Anyone with an account in Supabase Auth can sign in on /portal, /specs, /performance and the roadmap detail view, and read the protected content bundled with the site.
  • This admin page is restricted to accounts with the admin role (or the admin email).
  • Nothing else needs configuration on the hosting side — no Netlify functions, no env keys.

Grant access to a new partner

  1. Open the Supabase dashboard → your project → Authentication → Users.
  2. Add user → Create new user: enter the partner's email and a generated password, and turn ON Auto Confirm User.
  3. Send the credentials to the partner over a secure channel. Done — they can sign in immediately.

Revoke or reset

  • Revoke access: delete the user in Authentication → Users. Their login stops working instantly.
  • Reset a password: edit the user → Send password recovery (requires SMTP configured), or delete and recreate the account with a new password.

Make an account an admin

  1. Authentication → Users → click the user → Edit user.
  2. Under app_metadata, set {"roles": ["admin"]} and save.
  3. The user gains access to this admin page on their next sign-in. (The account admin@gmail.com is always treated as admin.)
